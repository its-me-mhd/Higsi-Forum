# Higsi Forum

A full-featured forum platform divided into a dedicated Admin CMS for moderation and an intuitive interface for everyday visitors.

## Features

### Visitor Site
* Discussion Boards: Browse categories, read threads, and engage in community discussions.
* User Authentication: Secure signup, login, and session management.
* Profile Management: Users can manage their personal details and track their forum activity.

### Admin CMS
* Content Moderation: Approve, edit, or remove user posts and threads to maintain community guidelines.
* User Management: View registered users, manage roles, and apply bans or warnings.
* Dashboard Analytics: Monitor forum activity, daily active users, and content metrics.
